## Unity 2022.3

- VideoPlayer API: https://docs.unity3d.com/2022.3/Documentation/ScriptReference/Video.VideoPlayer.html
- VideoPlayer audio track control: https://docs.unity3d.com/2022.3/Documentation/ScriptReference/Video.VideoPlayer-controlledAudioTrackCount.html
- VideoPlayer EnableAudioTrack: https://docs.unity3d.com/2022.3/Documentation/ScriptReference/Video.VideoPlayer.EnableAudioTrack.html
- iOS environment setup: https://docs.unity3d.com/2022.3/Documentation/Manual/ios-environment-setup.html
- iOS build process: https://docs.unity3d.com/2022.3/Documentation/Manual/iphone-BuildProcess.html
- Embedded packages: https://docs.unity3d.com/2022.3/Documentation/Manual/upm-embed.html

## Boundary note

These public API references do not provide or imply access to VRChat's proprietary client implementation or AVPro source code. The project observes only public behavior and uses original code.
