# Basic Harness

The repository already contains `Assets/Scenes/IOSVideoBridgeTest.unity`.

For another Unity project:

1. Add `IOSVideoTestHarness` to an empty GameObject.
2. Enter Play Mode.
3. Use the immediate-mode control panel to load a bundled or remote media URL.

The harness creates and configures its `VideoPlayer`, `AudioSource`, diagnostics, analyzer, and recovery components at runtime.
